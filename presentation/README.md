## Identidade Visual (Marca, Design)

A identidade visual do projeto foi pensada para transmitir os valores e propósitos da plataforma.

A cor roxa foi escolhida por representar criatividade, consciência e transformação, elementos que se conectam com a ideia de reaproveitamento e novo ciclo das roupas dentro do projeto.

Já o símbolo da folha representa sustentabilidade, reforçando o compromisso do sistema com práticas mais conscientes e ecológicas.
